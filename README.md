# TheSmp

A configurable SMP core plugin for Paper and Spigot, with homes, teleports, warps, trades, reports, menus, moderation, player profiles, rewards, quests, clans, and localized messages.

## Requirements

- Java 21
- Paper or Spigot 1.21.x

## Build

Run `mvn clean package`. Maven writes the plugin JAR to `target/`.

Default settings and messages are packaged from `src/main/resources/`.
